# Free asset pointers (links only — verify license before ship)

These are **starting points**, not endorsements. Always check license (CC0 vs attribution).

| Need | Where to look |
|------|----------------|
| CC0 game packs | https://kenney.nl |
| Mixed free game art | https://opengameart.org |
| HDRIs / PBR (3D) | https://polyhaven.com |
| Fonts | https://fonts.google.com (check OFL) |
| SFX (if not using make-sfx.py) | https://freesound.org (filter by license) |

**FI preference:** synthesize SFX with `tools/make-sfx.py` and draw placeholders first so you are never blocked on downloads.

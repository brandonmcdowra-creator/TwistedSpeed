Your game boots.
Now make it yours.

First AI builds are rough on purpose. This is the simple loop that keeps you in charge — without needing the same chat, or the same AI, forever. Works with a FutureIndustries build pack or as a standalone kit dropped into any game project you started outside FI.

🤖
Any AI tool Cursor · Claude · Codex · whatever you use next week
📋
One prompt file RUN-DESIGN-LAB.txt — paste it whole
📁
Any game folder FI pack or drop this kit next to Unity / Godot / web / etc.
1

Tell your AI to run the Design Lab prompt

Open this project folder in your AI tool. Paste everything in RUN-DESIGN-LAB.txt. It will create or refresh the Design Lab from your game as it is right now (and update changelog-style progress files).

↓
2

Open the lab · fill what you can · export

Open fi-design-lab/DESIGN-LAB.html. Seal phases that matter. Export answers (lab-answers.json / .md). Drop those files back into the project (or attach them) and tell your AI: “Read my lab export and plan the next slice.”

↓
3

Build · play · run it again

Let the AI implement one clear next step. You playtest (web/index.html). When things drift or a new AI takes over, go back to step 1 — paste RUN-DESIGN-LAB.txt again. The lab re-reads the pack so it doesn’t go stale.

THE LOOP (ONE LINE)

Prompt → Lab → Export → AI builds → You play → Prompt again

Memory lives in the folder: CHANGELOG.md, PROGRESS.md, game files, lab exports — not in a chat bubble that disappeared.

Don’t need the same conversation forever. Do keep this folder as the source of truth.

# Unity track — TwistedSpeed (Night Circuit)

**Status:** Playable NFS-leaning vertical slice · Pipeline online when Editor is open.

## Play

1. Unity **6000.5.5f1** → open `TwistedSpeed`
2. `Assets/Scenes/SampleScene` → **Play**
3. Title → **Garage** (Marrow turntable) → **Map** → **Race**

### Controls

| Input | Action |
|-------|--------|
| WASD | Drive (smoothed) |
| Shift | Drift |
| Ctrl / Space | Nitro |
| J / K / L | MG / Rocket / Mine |
| C · 1 / 2 / 3 | Cameras |
| Esc | Forfeit |

### Maps

1. **Neon Sepulcher** — dense city night, rivals, guillotine, oil, spikes  
2. **Spine Pass** — mountain look-first  
3. **Blackwater Coast** — coastal palms / piers

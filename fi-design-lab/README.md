# Design Lab (tooling — not the game)

**FutureIndustries Design Lab** — works inside an FI build pack **or** as a **standalone kit** next to any game you started outside FI.

## Flow

1. Put this kit in your **game project root** (or open that root in your AI).
2. Open **`../LOOK-AT-ME.html`** for the 3-step loop picture.
3. Paste **`../RUN-DESIGN-LAB.txt`** into any coding AI.
4. AI detects FI pack vs standalone, reads **code + docs**, fills coach notes + top AI summary.
5. Open **`DESIGN-LAB.html`**, fill, export.
6. Give export + project to AI → build → play → re-run the prompt when things drift.

## Standalone minimum kit
`RUN-DESIGN-LAB.txt`, `LOOK-AT-ME.html` (optional), `fi-design-lab/DESIGN-LAB.html`, `fi-design-lab/lab-state.json` — plus your actual game source.
